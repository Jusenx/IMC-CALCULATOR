# IMC Calculator

IMC Calculator é um site simples para calcular o Índice de Massa Corporal (IMC) com base no peso e altura do usuário. O objetivo é fornecer uma ferramenta rápida e intuitiva para avaliar a saúde corporal.

# Site de teste

https://jusenx.github.io/IMC-CALCULATOR/

## Tecnologias Utilizadas

- **HTML**
- **CSS**
- **JavaScript**

## Funcionalidades

- Inserir peso e altura para calcular o IMC
- Exibir a classificação do IMC com base na tabela da OMS
- Interface simples e responsiva
- Imagens ilustrativas para cada grau de saúde que você se encontra

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/Jusenx/IMC-CALCULATOR.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd IMC-CALCULATOR
   ```
3. Abra o arquivo `index.html` em seu navegador.
